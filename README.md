My version of 2D Car racing Game using GLUT C++ OpenGL
The 2D Car Racing Simulation is an interactive OpenGL application developed in C++ using the
GLUT library. This Simulation features a simple yet engaging gameplay where the player controls a
car on a vertically scrolling road while avoiding obstacles and aiming to achieve the highest possible
score,it also provides an illusion of the car moving on a road, even though the car is actually stationery.
The game includes a start screen, dynamic obstacle generation, collision detection, and speed control,
providing an immersive gaming experience.The keyboard functions used provide an appropriate
control on the movement of the road and the car.here,backward movement of the road ,simulates
forward movement of the car , and forward movement of the road,indicates backward movement of the
car. This project demonstrates the application of computer graphics principles, real-time rendering,
and user interaction handling in game development.
